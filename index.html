Orchestrator

Command Center

The read-only control surface for the wider personal software ecosystem.

Actual webpage screenshot captured locally from Command Center.

Command Center brings the important state of independent services into one place without taking ownership of their databases. It is designed for quick orientation: what needs attention, which services are available, and where stale data should be treated carefully.

Design constraints: server-to-server read-only APIs, explicit online/offline/stale states, and local-first private deployment.

Academic workflow

CanvasFlow

A private academic dashboard shaped around the way I actually study.

Actual webpage screenshot captured locally from CanvasFlow.

CanvasFlow mirrors coursework, materials, notes, and planning into a local workspace so lecture content remains easy to find and semester work can be managed in one coherent flow.

Design constraints: Canvas credentials stay server-side, lecture materials stay separated by category, and local exports keep the workflow resilient.

Career workflow

CareerScout

A private Singapore opportunity catalogue and application pipeline.

Actual webpage screenshot captured locally from CareerScout.

CareerScout turns scattered internship discovery into a durable workflow: opportunities can be reviewed, matched against preferences, saved, and moved through clear next actions.

Design constraints: transparent matching, local application state, and explicit source provenance.

Health workflow

Fitness Tracker

A private health workspace that keeps recorded facts separate from estimates.

Actual webpage screenshot captured locally from Fitness Tracker.

The tracker records routines, completion history, meals, and future Apple Health summaries. It is intentionally loopback-only, with unknowns and assumptions kept visible instead of hidden behind false precision.

Design constraints: Apple Health interoperability, no unnecessary subscriptions, and data ownership first.

TutorHub

Build Your Skills With Tutors And Learners Alike!

During the COVID-19 pandemic, many businesses had to move their services online. TutorHub was our response to that challenge in the tuition sector.

We combined ideas from platforms such as Coursera and Fiverr to create a place where people could learn from one another. The guiding idea was simple: anyone can be both a learner and a tutor.

What makes it different: TutorHub gives tutors another way to find learners and manage the peaks and troughs that often come with tuition work.

We first built the project with the Python framework Flask, then began rebuilding it with Express.js.

RepoSense

NUS Orbital project · Apollo Level of Achievement

NUS Orbital Apollo 11
Level of Achievement for the Orbital Programme · 2026

View achievement certificate

We developed RepoSense for NUS Orbital, an independent summer software project programme, and completed the project at the Apollo achievement level.

RepoSense is a full-stack web application that ingests a public GitHub repository or ZIP archive and turns its codebase into an approachable architecture overview.

Its static-analysis pipeline scans the file tree, detects languages and frameworks, extracts JavaScript, TypeScript, and Python imports, traces supported request flows, and identifies likely entry points and module roles. Results are presented through repository metrics, module summaries, and an interactive dependency graph.

Tech stack: React, TypeScript, Vite, Tailwind CSS, Node.js, Express, Prisma, PostgreSQL, ELK, and the TypeScript and Python AST tooling.
